# Governance Gap Assessment

Eight gaps identified across eight governance domains, comparing current state against target state. Six of the eight gaps carry **High** priority.

## Gap Summary

| Gap ID | Governance Domain | Priority | Owner | Status |
|---|---|---|---|---|
| G-001 | AI Inventory | High | AI Governance Lead | Open |
| G-002 | Risk and Impact Assessment | High | Enterprise Risk Lead | Open |
| G-003 | Human Oversight | High | Business System Owners | In Progress |
| G-004 | Data Governance | High | Data Governance Lead | Open |
| G-005 | Monitoring and Logging | Medium | AI Operations Lead | Open |
| G-006 | Third-Party AI | High | Procurement Lead | Open |
| G-007 | AI Literacy | Medium | Learning and Development Lead | Open |
| G-008 | Incident Response | High | CISO / AI Governance Lead | Open |

## G-001 — AI Inventory

| Field | Detail |
|---|---|
| Current State | Known tools listed manually |
| Target State | Complete, owned, regularly reviewed inventory |
| Gap / Finding | No formal discovery process for new or unapproved AI tools. |
| Risk Priority | High |
| Recommended Action | Establish intake process, quarterly attestation, and Shadow AI discovery review. |
| Owner | AI Governance Lead |
| Target Date | 2026-10-31 |
| Status | Open |
| Evidence Required | Approved inventory; attestations; discovery report |
| Framework Mapping | NIST GOVERN 1; ISO/IEC 42001 context and inventory |

## G-002 — Risk and Impact Assessment

| Field | Detail |
|---|---|
| Current State | Assessments vary by project |
| Target State | Consistent risk-based assessment before approval |
| Gap / Finding | No standard AI impact assessment template or approval threshold. |
| Risk Priority | High |
| Recommended Action | Adopt one assessment covering purpose, stakeholders, data, rights, safety, security, and residual risk. |
| Owner | Enterprise Risk Lead |
| Target Date | 2026-09-30 |
| Status | Open |
| Evidence Required | Completed AIIA; approval decision |
| Framework Mapping | NIST MAP; EU AI Act risk-based approach |

## G-003 — Human Oversight

| Field | Detail |
|---|---|
| Current State | Oversight exists but is not consistently documented |
| Target State | Clearly defined HITL, HOTL, or HIC controls |
| Gap / Finding | Override authority and escalation triggers are unclear for two high-impact systems. |
| Risk Priority | High |
| Recommended Action | Document oversight model, pause authority, escalation trigger, and appeal route. |
| Owner | Business System Owners |
| Target Date | 2026-09-30 |
| Status | In Progress |
| Evidence Required | RACI; operating procedure; test record |
| Framework Mapping | EU AI Act human oversight; OECD accountability |

## G-004 — Data Governance

| Field | Detail |
|---|---|

| Risk Priority | High |
| Recommended Action | Create source register, provenance checks, quality rules, and retention review. |
| Owner | Data Governance Lead |
| Target Date | 2026-10-15 |
| Status | Open |
| Evidence Required | Data sheet; lineage; quality report |
| Framework Mapping | EU AI Act data governance; NIST MAP/MEASURE |
